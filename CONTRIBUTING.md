# Contributing / Adding a New Interview Question

## One-question workflow

When a new question is received:

1. Search `Question-Bank/` for an existing question.
2. If it already exists, add the company reference only.
3. If it is new:
   - assign the next ID in the appropriate topic file,
   - add a Simple Explanation,
   - add an Interview-Ready Answer,
   - add follow-up questions,
   - record the source/company,
   - then add the link to the relevant `Company-Wise/*.md` file.
4. Do not duplicate the full answer in the company file.

## Answer provenance

Use one of these labels:

- **Workbook source answer** — answer is directly supported by the supplied workbook.
- **Prepared interview answer** — answer is synthesized from workbook concepts plus standard interview knowledge.
- **Needs personal/project-specific answer** — the workbook does not provide enough information to invent the user's personal experience.

## Quality rules

- Keep answers technically accurate and interview-friendly.
- Prefer simple language first, then technical terminology.
- Do not invent project experience.
- Do not expose recruiter/contact information.
- Avoid duplicate questions.
