# How to Add New Interview Questions

## What to send

Use any of these formats:

- Text
- Screenshot
- Excel
- Notes
- Interview transcript

Minimum information:

```text
Company: Example Company
Questions:
1. What is Terraform state?
2. How do you secure an Azure DevOps pipeline?
```

## Processing Rules

1. Check whether the question already exists.
2. If it exists, add the new company under **Asked In**.
3. If it is new, classify it by topic.
4. Write a simple explanation.
5. Write a short interview-ready answer.
6. Add a real-world example where useful.
7. Add follow-up questions.
8. Never add recruiter/HR phone numbers or email addresses to this public repository.

## Git Commands

```bash
git add .
git commit -m "Add new DevOps interview questions"
git push
```
