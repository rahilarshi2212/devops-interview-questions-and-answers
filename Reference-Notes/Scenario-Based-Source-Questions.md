# Reference Notes — Scenario Based Qestion

This file preserves the source workbook's study topics/questions. It is reference material, not a claim that every listed topic has a supplied answer in the workbook.

- 1. *Scenario:* Terraform state file corrupt ho gaya. Production infra kaise recover kroge?
- 2. *Scenario:* Developer ne manually Azure portal se changes kr diye. *Configuration Drift* kaise handle kroge?
- 3. *Scenario:* Company ko *Highly Available* infra chahiye Azure me. Architecture kaise design kroge?
- 4. *Scenario:* Same Terraform code se *Dev, QA, Prod* deploy krna hai. Kaise manage kroge?
- 5. *Scenario:* Terraform deployment ke time *resource already exists* error aa rha hai. Kya kroge?
- 6. *Scenario:* Company ka pura infra manually bana hua hai. Terraform migration ka approach kya hoga?
- 7. *Scenario:* Azure VM internet pe exposed hai. Security improve kaise kroge?
- 8. *Scenario:* Terraform apply ke baad kuch resources create hue aur kuch fail ho gaye. Troubleshoot kaise kroge?
- 9. *Scenario:* Multiple DevOps engineers same infra pe kaam kr rhe hai. Conflict kaise avoid kroge?
- 10. *Scenario:* Production infra accidentally delete hone se kaise bachoge?
- 11. *Scenario:* Company ko *Disaster Recovery* setup chahiye. Terraform se kaise implement kroge?
- 12. *Scenario:* Azure infra ka cost bahut increase ho gaya. Optimization kaise kroge?
- 13. *Scenario:* Secrets Terraform code me hardcoded mil rhe hai. Secure approach kya hoga?
- 14. *Scenario:* AKS cluster deploy krna hai with *private networking* and *autoscaling*. Kaise kroge?
- 15. *Scenario:* CI/CD pipeline me Terraform automation ka complete flow explain kro.
- 16. *Scenario:* Company ko *Hub-Spoke Landing Zone* architecture banana hai. Steps kya honge?
- 17. *Scenario:* Terraform code reusable aur scalable kaise banaoge?
- 18. *Scenario:* Compliance team bol rhi hai sab resources pe tagging mandatory hai. Kaise enforce kroge?
- 19. *Scenario:* Production deployment me *zero downtime* maintain kaise kroge?
- 20. *Scenario:* Azure infra monitoring aur alerting Terraform se kaise setup kroge?
