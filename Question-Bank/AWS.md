## AWS-002 — Difference between Security Group and NACL? (AWS networking question)

**Asked In:** Wipro L3 Devops question
**Answer Type:** Prepared interview answer

### Interview-Ready Answer
An AWS Security Group is a stateful virtual firewall associated with network interfaces. It controls allowed inbound and outbound traffic. AWS Network ACLs are subnet-level stateless filters.

### Simple Explanation
Explain the concept in one or two sentences first, then connect it to how you would use or troubleshoot it in a real DevOps environment.

## AWS-003 — Difference between Security Groups and NACL.

**Asked In:** Wipro L3 Devops question
**Answer Type:** Workbook source answer

### Interview-Ready Answer
- NSGs: Azure NSGs are stateful Layer 4 firewalls that control inbound and outbound traffic to Azure resources based on rules. - ASGs: Azure ASGs allow logical grouping of VMs based on application-centric logic. They simplify security rule management by enabling rule configuration based on application memberships.
