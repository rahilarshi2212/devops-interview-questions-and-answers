## DOC-001 — ## Container Security

**Asked In:** Persistent Interview
**Answer Type:** Prepared interview answer

### Interview-Ready Answer
A container is a running instance of an image. It packages an application and its dependencies while sharing the host kernel rather than running a full guest operating system.

### Simple Explanation
Explain the concept in one or two sentences first, then connect it to how you would use or troubleshoot it in a real DevOps environment.

### Follow-up Questions
- How would you troubleshoot this in production?
- How would you secure the image/container?
- How would this work in CI/CD?

## DOC-002 — Can you explain a Multi-stage Dockerfile?

**Asked In:** All Interview Qestions
**Answer Type:** Prepared interview answer

### Interview-Ready Answer
A Dockerfile contains instructions used to build a Docker image. A typical build copies application files, installs dependencies, sets configuration, and defines the command used to start the container.

## DOC-008 — What is the difference between docker build and docker commit?

**Asked In:** TCS Qustion
**Answer Type:** Prepared interview answer

### Interview-Ready Answer
docker commit creates a new image from a container's current filesystem state. For repeatable builds, a Dockerfile is normally preferred.
