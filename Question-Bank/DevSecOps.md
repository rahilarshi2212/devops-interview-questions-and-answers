## SEC-001 — ## SonarQube

**Asked In:** Persistent Interview
**Answer Type:** Prepared interview answer

### Interview-Ready Answer
SonarQube performs static code analysis to identify issues such as bugs, vulnerabilities, code smells, and coverage-related quality conditions. In CI/CD it can publish a quality gate that controls promotion.

**Asked In:** NAB & Quess Interview
**Answer Type:** Prepared interview answer

### Interview-Ready Answer
